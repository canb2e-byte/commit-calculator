# 집 PC용 로컬 출퇴근 수집기

## 실행

1. Python 3.10 이상을 설치하세요. Windows 설치 화면에서 `Add Python to PATH`를 선택하세요.
2. ZIP을 쓰기 가능한 폴더에 모두 풀고 `START.bat`을 더블클릭하세요.
3. 처음 실행할 때 Excel 저장용 openpyxl이 없으면 설치합니다. 인터넷 연결이 필요합니다.
4. 브라우저의 `http://127.0.0.1:8765`에서 카카오 REST API 키를 입력하고 설정 저장을 누르세요.
5. 실행 창을 열어 두면 수집합니다. 중지는 실행 창에서 `Ctrl+C`입니다.

직접 실행하려면 이 폴더의 터미널에서 `python -m pip install -r requirements.txt`, 다음 `python commute_tracker.py`를 실행하세요.

## 수집 조건

- 기간: 2026-11-24 16:00부터 2026-12-31 20:00까지, 한국 시각.
- 평일 05:00~10:00: 집 → 회사 두 경로만, 10분 간격.
- 평일 16:00~20:00: 회사 → 집 두 경로만, 10분 간격.
- 집: 경기도 수원시 영통구 봉영로1517번길 73.
- 회사: 세종특별자치시 소정면 소정산단4로 31.
- 경유지: 충남 천안시 동남구 풍세면 풍서리 산 18-3.
- 경로 A: 위 경유지를 지나는 시간 우선 경로. 경로 B: 거리 우선 경로.
- 예상시간, 거리, 조회 날짜·요일·시각, 도로명과 확인 상태를 기록합니다.
- 집/회사 출발지 날씨: 기온, 습도, 강수량, 비, 강설, 풍속과 날씨 기준 시각을 기록합니다.
- 실제 운행시간은 별도로 출발·도착 버튼을 누른 기록입니다.

## 파일

- `commute_data.sqlite3`: 원본 누적 데이터.
- `commute_data.xlsx`: 예상시간·실제운행·안내 시트. 매번 로컬 데이터에서 갱신합니다.
- `collection-health.json`: 매 수집 뒤 API 결과와 SQLite/Excel 행 수를 점검한 결과.
- `settings.json`: 화면에서 입력한 API 키, 조회 간격과 기간 설정. 처음 저장할 때 생깁니다.

Excel을 열어 두어 덮어쓰기가 막히면 화면에 저장 오류가 표시되지만 원본 DB 기록은 남습니다. Excel을 닫은 뒤 다음 수집을 기다리거나 Excel 저장 버튼을 누르면 다시 반영됩니다.

집 PC의 시간대는 한국으로 설정하세요. PC가 꺼지거나 절전 상태면 수집하지 않습니다. 다시 켠 뒤 START.bat을 실행해야 하며, 빠진 시간대의 과거 교통정보를 채우지는 못합니다. 회사와 집에서 동시에 실행하면 각 PC에 데이터가 따로 쌓입니다.

기간을 바꾸려면 종료 후 `settings.json`의 `collection_start`, `collection_end`를 `2026-12-31T20:00:00+09:00` 같은 형식으로 수정하세요. 기본 평일 설정은 공휴일을 따로 제외하지 않습니다.

카카오 Local 주소 조회 및 카카오모빌리티 길찾기 권한이 있는 키가 필요합니다. 날씨는 Open-Meteo의 격자 기반 현재 자료이며 집/회사 좌표를 그 서비스에 전송합니다. API 한도/이용 조건은 각 서비스 정책을 따릅니다. 공식 문서: https://developers.kakao.com/docs/latest/ko/local/dev-guide , https://developers.kakaomobility.com/docs/navi-api/directions/ , https://open-meteo.com/en/docs .

패키지에는 API 키나 회사 PC에서 수집한 기록을 넣지 않았습니다. 전체 실행 코드가 포함되어 있습니다.
